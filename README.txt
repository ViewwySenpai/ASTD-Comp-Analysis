============================================
 ASTD Hub — โครงสร้างโปรเจกต์
============================================

astd-site/
├─ index.html              → หน้า DPS Calculator
├─ units.html              → หน้ารวมยูนิตทั้งหมด (การ์ด + รูป คลิกไปคำนวณได้)
├─ mobhp.html              → หน้าตารางเลือดมอน (Anchor Table)
├─ team.html               → หน้าจัดทีม 1-4 คน + การ์ดลากเรียงลำดับ
├─ template.html           → แม่แบบสร้างหน้าใหม่ (Save As แล้วแก้)
├─ README.txt              → ไฟล์นี้
└─ assets/
   ├─ css/style.css        → สไตล์กลาง ใช้ร่วมกันทุกหน้า
   ├─ js/units.js          → ฐานข้อมูลยูนิต (แก้/เพิ่มยูนิตที่นี่)
   ├─ js/calculator.js     → ตรรกะหน้า Calculator
   ├─ js/hpcore.js         → สูตรเลือดมอน + ตัวคูณผู้เล่น (ใช้ร่วม Mob HP กับ Team)
   └─ img/
      ├─ logo.png          → (ยังไม่มี) วางโลโก้ทับที่นี่
      └─ units/            → (ยังว่าง) วางรูปยูนิตที่นี่

--------------------------------------------
1) โลโก้มุมซ้ายบน
--------------------------------------------
เขียนทับไฟล์:   assets/img/logo.png
ขนาด:           256 x 256 px (PNG พื้นหลังโปร่งใส)
พอวางไฟล์แล้วรีเฟรช โลโก้จะขึ้นแทนช่องว่างทุกหน้าอัตโนมัติ

--------------------------------------------
2) รูปตัวละคร / ยูนิต
--------------------------------------------
โฟลเดอร์:  assets/img/units/
ขนาด:      200 x 200 px (PNG)
ชื่อไฟล์:   ดูใต้การ์ดในหน้า Units หรือใต้ชื่อยูนิตในหน้า Calculator
           ตัวพิมพ์เล็ก เว้นวรรค/วงเล็บ → ขีดกลาง
           "Koku (Supa)" → koku-supa.png / "Freezer [FULL]" → freezer-full.png

--------------------------------------------
3) เพิ่ม/แก้ยูนิต — assets/js/units.js
--------------------------------------------
["ชื่อ", Damage, SPA, Range, TotalCost, "Ground/Air/Hybrid", "AtkType", "Enchant", isNew, star]
- ยังไม่รู้สถิติ → ใส่ null (เว็บจะให้กรอกเองในหน้า Calculator)
- isNew = 1 → ป้าย NEW / star = 7 → ป้าย 7★
- Enchant ที่มีสีป้าย: Water, Dark, Holy, Nature, Electric

--------------------------------------------
4) สูตรเลือดมอน + ตัวคูณ — assets/js/hpcore.js
--------------------------------------------
- ANCHORS       : จุดยึดค่าจริงในเกม (Wave : HP) เพิ่มได้เรื่อยๆ ยิ่งเพิ่มยิ่งแม่น
- EARLY_HP      : HP จริง Wave 1-30 (Wave 1 = 41)
- PLAYER_MULTS  : ตัวคูณจำนวนผู้เล่น = 1 คน x1.0 / 2 คน x1.9 / 3 คน x2.8 / 4 คน x3.7
- ENEMY_MULTS   : Weak x1.00 / Medium x1.30 / Strong x1.75
แก้ไฟล์นี้ไฟล์เดียว มีผลทั้งหน้า Mob HP และหน้า Team

--------------------------------------------
5) หน้า Team — ลำดับการ์ด
--------------------------------------------
- เปิดสวิตช์การ์ดทางซ้าย → การ์ดจะไปโผล่ในลิสต์ "ลำดับการใช้การ์ด" ทางขวา
- ลากสลับ หรือกด ▲▼ เพื่อจัดลำดับ (ลำดับมีผลจริงต่อการคำนวณ)
- Gilgamesh / Madara ตัดเลือด "ลงไปที่ %ของเลือดเต็ม"
  → กด Gilgamesh (25%) ก่อน แล้วกด Madara (33%) จะไม่มีผล เพราะเลือดต่ำกว่าอยู่แล้ว
  → ถ้า Madara มาก่อน (เหลือ 33%) แล้ว Gilgamesh ตามมา จะตัดต่อเหลือ 25% ได้
- Luffy ตัดเลือด "ที่เหลืออยู่" ลง 25% (บัฟเสริมเพิ่ม % การตัด)
- TBOI ระเบิดดาเมจคงที่ 250B (บัฟเสริมเพิ่มดาเมจ, Dot Buff +50% เฉพาะ TBOI)
- บัฟเสริม: Idol 15% / Judgement 8% / FV 35% / Purify 12% (กดเลือกหลายอันพร้อมกันได้)

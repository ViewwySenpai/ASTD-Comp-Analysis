5) หน้า Team
--------------------------------------------
- เลือกยูนิต: กดรูปหรือชื่อในแถวยูนิต จะเปิดกริดรูปให้เลือก (ค้นหา + กรอง 6★/7★
  /เฉพาะตัวที่มีสถิติ) ไม่ต้องพิมพ์ในดรอปดาวน์แล้ว
  เลือก "กรอก DPS เอง" ได้ถ้าอยากใส่ตัวเลขตรงๆ
- แต่ละแถวเลือกได้เอง: ขั้นอัปเกรด + บัฟดาเมจ (100 / 250 / 300%) + จำนวนตัวที่วาง
  ขั้นอัปเกรดจะมีให้เลือกเฉพาะยูนิตที่มีตารางใน assets/js/upgrades.js
  วิธีคิด: DPS = DPS เต็ม x (DPS ขั้นที่เลือก / DPS ขั้นสุดท้าย) x บัฟ x จำนวนตัว
  (ทำแบบนี้เพราะ upgrades.js เก็บตัวเลข Level 1 แต่ units.js เป็น Level 175
   ถ้าเอามาใช้ตรงๆ สเกลจะไม่ตรงกัน)
- การ์ด: กดปุ่ม "ใส่ในลำดับการ์ด" ที่การ์ด แล้วไปลากเรียงทางขวา (เดิมเป็นสวิตช์)
  กดปุ่มเดิมซ้ำได้ = ใส่การ์ดใบเดิมหลายใบ เอาออกด้วยปุ่ม ✕ ในลำดับทางขวา
  Team DPS แต่ละใบตั้งจำนวนวินาทีของตัวเองได้ในลำดับ และมีบัฟ
  Idol / Judgement / FV / Purify บนตัวการ์ด (คูณกับ DPS รวมของทุกทีม)
- ใต้ชื่อการ์ดแต่ละใบในลำดับ บอกว่าหลังใบนั้นเลือดมอนเหลือกี่ % ของเลือดเต็ม
  สีเขียว > 66% / เหลือง 34-66% / ส้ม <= 33% / แดง = ตายแล้ว
- Gilgamesh / Madara ตัดเลือด "ลงไปที่ %ของเลือดเต็ม"
  -> กด Gilgamesh (25%) ก่อน แล้วกด Madara (33%) จะไม่มีผล เพราะเลือดต่ำกว่าอยู่แล้ว
- Luffy ตัดเลือด "ที่เหลืออยู่" ลง 25% / TBOI ระเบิดคงที่ 250B (บัฟเสริมเพิ่มให้)
- ตัวเลข DPS ใต้ชื่อยูนิตคือ DPS จริงของแถวนั้น (คิดขั้นอัปเกรด + บัฟ + จำนวนตัวแล้ว)
  ขยับตามทันทีที่เปลี่ยนค่า และแต่ละทีมมีป้ายบอก DPS รวมของทีมนั้นด้วย
- ถ้าเคลียร์ไม่ได้ กล่องสรุปจะบอกเลือดที่เหลือ + คิดเป็นกี่ % ของเลือดเต็ม
- ยูนิตตัวแรกของแต่ละทีม = Leader (มีป้ายบนรูป) ลบตัวแรกออก ตัวถัดไปขึ้นเป็น Leader แทน
  สกิลของ Leader จะบัฟเพื่อนร่วมทีมที่มีหมวดตรงกับที่สกิลระบุ ตัวเองก็ได้ถ้าอยู่ในหมวดนั้น
  ยูนิตที่ได้บัฟจะมีบรรทัดเล็ก ๆ บอกใต้ชื่อ และ DPS คิดรวมให้แล้ว
  ตัวเลขที่เอาไปคิดอยู่ที่ boost ใน assets/js/categories.js (cat = หมวดที่บัฟ, atk = กี่ %)
  ยูนิตที่ยังไม่มีข้อมูลหมวดจะไม่ได้บัฟ เพราะระบบไม่รู้ว่ามันอยู่หมวดไหน
- โค้ดหน้านี้อยู่ที่ assets/js/team.js ไฟล์เดียว ใช้ร่วมกันทั้งไทยและอังกฤษ

7) ขั้นอัปเกรดของยูนิต (ใหม่)
--------------------------------------------
หน้า Calculator มีแผง "ขั้นอัปเกรด" กดขั้นไหนก็ได้ ค่า Damage / SPA / Range
และราคาสะสมจะเด้งขึ้นช่องด้านบนทันที พร้อมตารางเทียบ DPS ทุกขั้น

ตอนนี้มีข้อมูลจริงจากวิกิแล้ว 4 ตัว:
  - Aqua Koku   11 ขั้น
  - Tokens      10 ขั้น
  - Veguko       7 ขั้น
  - Ultra Koku   5 ขั้น
7 ดาว:
  - Heavenly Duo       8 ขั้น (Gilgamesh — ราคารวม 20,000,000 ตรงกับวิกิ)
  - Ant King (Awakened) 7 ขั้น
(ตัวเลขเป็นคอลัมน์ Level 1 ของวิกิ)

ตัวอื่นเติมเองได้เร็วมาก:

  1. เปิดหน้ายูนิตนั้นบนวิกิ
  2. ลากคลุมบล็อก Stats Overview ทั้งก้อน (Deployment ถึง Upgrade สุดท้าย) แล้วก๊อป
  3. กลับมาหน้า Calculator เลือกยูนิตนั้น กางหัวข้อ "นำเข้าตารางอัปเกรด"
     วางข้อความลงไป กด "อ่านข้อมูล"
  4. เว็บแปลงเป็นตารางให้ทันที และจำไว้ในเบราว์เซอร์

อยากเก็บถาวรให้ทุกคนที่เข้าเว็บเห็นด้วย: กด "คัดลอกเป็นโค้ด"
แล้วเอาไปวางต่อท้ายใน assets/js/upgrades.js (ในวงเล็บปีกกาของ UPGRADES)

รูปแบบข้อมูลในไฟล์:
  "slug": [
    {lv:0, cost:500, dmg:7500, rng:30, spa:6},   ← lv:0 = วางครั้งแรก
    {lv:1, cost:500, dmg:27500, rng:30, spa:6},
  ],
  * cost = ราคาของขั้นนั้น ไม่ใช่ยอดสะสม (เว็บบวกสะสมให้เอง)
  * slug ดูได้ใต้รูปยูนิตในหน้า Calculator

หมายเหตุ: ผมดึงข้อมูลจากวิกิมาได้แค่ตัวเดียวเพราะเว็บวิกิเริ่มบล็อกการดึงหน้า
จึงไม่ใส่ตัวเลขตัวอื่นให้ เพราะไม่อยากเดาค่าที่ไม่ได้ยืนยัน

  key = slug ของยูนิต / lv = ปลดล็อกที่อัปขั้นไหน
  cd = คูลดาวน์ / global:true = คูลดาวน์ร่วมกับยูนิตอื่น
  th กับ en = รายละเอียดเป็นข้อ ๆ (ต้องใส่ทั้งสองภาษา)
  passive:true = เป็น passive ไม่ใช่สกิลกด (ท้ายการ์ดจะไม่ขึ้นคำว่า "คูลดาวน์")
  mult:1.5     = ใส่แล้วการ์ดจะมีสวิตช์เปิด-ปิด เปิดแล้วดาเมจคูณตามเลขนี้
                 คูณในกลุ่มเดียวกับบัฟ 250/300% (ไม่ใช่กลุ่ม Leader/Orb)
                 ปุ่ม "ล้างบัฟ" ปิดสวิตช์นี้ด้วย

14) บัฟในหน้า Calculator
--------------------------------------------
เอาหลอดเลื่อนออกแล้ว เหลือปุ่ม:
  บัฟดาเมจ   250% / 300%
  บัฟ Leader 15% / 20%
  บัฟเสริม   Idol +15% / Judgement +8% / FV +35% / Purify +12% (เลือกได้หลายอัน)
  Orb        เลือกได้ทีละลูก กดซ้ำเพื่อถอด (ข้อมูลอยู่ที่ assets/js/orbs.js)
กดปุ่มเดิมซ้ำ = ปิดบัฟนั้น / กดคนละแถวพร้อมกันได้ ค่าจะ "คูณกัน" ไม่ใช่บวก
  เช่น 250% กับ Leader 20% = x3.5 * x1.2 = x4.2 (ช่องตัวเลขจะขึ้น 320%)
  ปุ่มบัฟเสริมในหน้า Team (Idol / Judgement / FV / Purify) ก็คูณกันแบบเดียวกัน
ช่องตัวเลขขวามือยังพิมพ์เองได้ (พิมพ์แล้วปุ่มจะเลิกไฮไลต์)


--------------------------------------------
15) Judgement DPS ในตารางขั้นอัปเกรด
--------------------------------------------
ใส่ jdg:true ในแถวของ upgrades.js ระบบจะเพิ่มช่อง Judgement DPS ให้เอง
DPS ที่เว็บใช้ทุกหน้า (Calculator / Team / Compare) = DPS ปกติ + Judgement DPS
สูตร Judgement DPS: ดาเมจ x 0.25 x 10 / ตัวหาร
ตัวหาร = รอบยิงที่ครอบ 20 วินาทีพอดี คือ ceil(20/SPA) x SPA
  SPA 5 -> 20 / SPA 7 -> 21 / SPA 9 -> 27 / SPA 14 -> 28
ตอนนี้ใช้กับ Second Trumpet: Salt King ตัวเดียว
DPS ของยูนิตแบบนี้ = DPS ปกติ + Judgement DPS ทุกหน้าคิดรวมให้แล้ว
(หน้า Calculator, Compare, Team) ตัวช่วยอยู่ที่ unitTotalDps() ใน upgrades.js

16) Orb — assets/js/orbs.js
--------------------------------------------
เพิ่ม/แก้ Orb ได้ในไฟล์นี้ไฟล์เดียว ปุ่มในหน้าเว็บสร้างจากลิสต์นี้อัตโนมัติ
  dmg  = Overall DMG Buff %   -> คูณกับดาเมจ (คูณต่อกับบัฟอื่น)
  cost = ลดราคารวม %          -> มีผลกับค่า "คุ้มต่อ 1,000¢" เท่านั้น
  range= ช่อง Initial-RNG ของวิกิ (RNG = Range ไม่ใช่ค่าสุ่ม)
         คูณเฉพาะ "ระยะตอนวางครั้งแรก" ใส่ค่าติดลบได้
                                 ระยะที่ได้จากการอัปเกรดบวกทีหลัง ไม่โดนคูณ
                                 เช่น วางครั้งแรก 40 อัปแล้วเป็น 100 (บวกมา 60)
                                 ใส่ orb +20% -> 40x1.2 + 60 = 108
                                 ระยะตั้งต้นอ่านจากแถวแรกของตารางใน upgrades.js
                                 ยูนิตที่ยังไม่มีตาราง จะคูณทั้งก้อนไปก่อน
  from = ได้มาจากไหน (ต้องใส่ทั้ง th กับ en)

20) นับจำนวนคนเข้าเว็บ — assets/js/analytics.js
--------------------------------------------
ต้องเอาเว็บขึ้นโฮสต์ก่อน เปิดจากไฟล์ในเครื่องนับไม่ได้

  1. เอาโฟลเดอร์นี้ขึ้น Cloudflare Pages (ฟรี ลากโฟลเดอร์ไปวางได้เลย)
  2. dash.cloudflare.com -> Web Analytics -> Add a site -> ใส่โดเมน
  3. ก๊อป token มาวางที่บรรทัด CF_TOKEN ใน assets/js/analytics.js

ไม่ใช้คุกกี้ ไม่เก็บข้อมูลส่วนตัว ไม่ต้องมีแบนเนอร์ขอความยินยอม

อยากเปลี่ยนไปใช้เจ้าอื่น (GoatCounter / Umami) ก็แก้ไฟล์นี้ไฟล์เดียว
ทุกหน้าโหลดไฟล์นี้อยู่แล้ว

--------------------------------------------
22) ดาเมจตายตัวจากสกิล (ช่อง flat ใน upgrades.js)
--------------------------------------------
บางสกิลเพิ่มดาเมจพื้นฐานแบบตายตัว ไม่ใช่คูณ % เช่น
Seraph's Rebirth ของ Second Trumpet: Salt King (+221,760,000)

ใส่เป็นแถวเพิ่มในตารางขั้นอัปเกรด:
  {lv:9, cost:0, dmg:<ดาเมจฐานเดิม>, flat:<ดาเมจที่เพิ่มแบบตายตัว>,
   rng:.., spa:.., name:"ชื่อที่จะโชว์บนหัวกล่อง", note:{th:..,en:..}}

  dmg  = ส่วนที่บัฟทุกอย่างคูณได้ตามปกติ
  flat = ส่วนตายตัว  Leader กับ Orb คูณไม่ได้
                     แต่บัฟ 250/300%, Support และธาตุคัดแพ้ยังคูณได้
  name = ใส่แล้วหัวกล่องจะใช้ชื่อนี้แทนคำว่า "อัป 9"

แถวที่มี flat จะไม่ถูกใช้เป็นตัวอ้างอิงของขั้นสูงสุดในหน้า Team
(ขั้นสูงสุดจริงคือแถวสุดท้ายที่ไม่มี flat = ตรงกับสถิติใน units.js)

ข้อจำกัดที่รู้อยู่: ในหน้า Team บัฟจาก Leader จะคูณส่วน flat ไปด้วย
เพราะหน้านั้นคิดจากสัดส่วนของขั้นอัปเกรด ไม่ได้แยกสองส่วนเหมือนหน้า
Calculator กับ Compare

--------------------------------------------
1) โลโก้มุมซ้ายบน
--------------------------------------------
เอาไฟล์โลโก้ไปเขียนทับที่:   assets/img/logo.png
ขนาดที่ต้องใช้:              256 x 256 px (สี่เหลี่ยมจัตุรัส)
                            PNG พื้นหลังโปร่งใสจะสวยสุด
ตอนยังไม่มีไฟล์ หน้าเว็บจะโชว์ช่องว่างเขียนว่า "ใส่โลโก้ 256×256"
พอวางไฟล์แล้วรีเฟรช โลโก้จะขึ้นแทนทันที (ทุกหน้า)

--------------------------------------------
2) รูปตัวละคร / ยูนิต
--------------------------------------------
โฟลเดอร์:      assets/img/units/
ขนาดที่ต้องใช้: 200 x 200 px (สี่เหลี่ยมจัตุรัส PNG)
ชื่อไฟล์:       ดูได้ 2 ที่
               - หน้า Units: เขียนไว้ใต้การ์ดของทุกตัว เช่น  koku.png
               - หน้า Calculator: เขียนใต้ชื่อยูนิตที่เลือกอยู่
กติกาชื่อไฟล์: ตัวพิมพ์เล็กทั้งหมด เว้นวรรค/วงเล็บ → ขีดกลาง (-)
               เช่น "Koku (Supa)"        → koku-supa.png
                    "Freezer [FULL]"     → freezer-full.png
                    "Universe Justice #1"→ universe-justice-1.png
เขียนทับ/เพิ่มไฟล์ได้เลย รีเฟรชแล้วรูปขึ้นอัตโนมัติ ไม่ต้องแก้โค้ด

--------------------------------------------
3) เพิ่ม/แก้ยูนิต
--------------------------------------------
เปิด assets/js/units.js  รูปแบบต่อบรรทัด:

["ชื่อ", Damage, SPA, Range, TotalCost, "Ground/Air/Hybrid", "AtkType", "Enchant", isNew],

- ยูนิตที่ยังไม่รู้สถิติ: ใส่ null แทนตัวเลข (เว็บจะขึ้น "ยังไม่มีสถิติ"
  แล้วให้กรอกเองในหน้า Calculator ได้)
- ใส่ 1 ท้ายบรรทัด = ขึ้นป้าย NEW / ไม่ใส่ = ยูนิตปกติ
- Enchant ที่มีสีป้าย: Water, Dark, Holy, Nature, Electric
- ยูนิตชุดที่มีสถิติครบ อ้างอิง Level 175 Max จาก:
  https://allstartd.fandom.com/wiki/Statistics

--------------------------------------------
4) เพิ่มหน้าใหม่ (Master Template + Save As)
--------------------------------------------
1. เปิด template.html → Save As เป็นชื่อหน้าใหม่ เช่น codes.html
2. แก้ <title>
3. แก้เมนู <nav class="mainnav"> ให้ตรงกันทุกหน้า
   (เพิ่มลิงก์หน้าใหม่ + ย้าย class="active" ไปหน้าปัจจุบัน)
4. ใส่เนื้อหาในส่วน <!-- CONTENT -->

--------------------------------------------
หมายเหตุข้อมูล
--------------------------------------------
- ยูนิตที่มีสถิติ = ทั้งหมดที่ตาราง Statistics ของ Wiki เปิดให้ดึงได้
- ยูนิตป้าย NEW = รายชื่อจากหน้า New Units ของ Wiki (ก.ค. 2026)
- ยูนิตป้าย 7★ = รายชื่อจากหน้า 7 Star Units ของ Wiki
  สองกลุ่มนี้ Wiki ไม่ลงสถิติในตาราง Statistics จึงเว้นไว้ให้กรอกเอง
- Buffs ในหน้า Calculator เหลือ: Damage Buff (ปุ่ม 250%/300%) + Elemental x1.5

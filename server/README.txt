ตัวนับผู้เข้าชม — วิธีติดตั้ง
============================================================

ทำไมต้องมีไฟล์ในโฟลเดอร์นี้
--------------------------------------------
โค้ดที่รันในเบราว์เซอร์มองไม่เห็น IP ของคนที่เปิดเว็บ
ต้องมีตัวรับฝั่งเซิร์ฟเวอร์คอยดู IP แล้วนับให้
ไฟล์ visitor-counter.js คือตัวนั้น รันบน Cloudflare Worker (ฟรี)


ขั้นตอน
--------------------------------------------
1) เข้า dash.cloudflare.com -> Workers & Pages -> Create -> Worker
   ตั้งชื่ออะไรก็ได้ เช่น astd-visitors แล้วกด Deploy

2) กด Edit code เอาเนื้อในไฟล์ visitor-counter.js ไปวางทับทั้งหมด แล้ว Deploy

3) สร้างที่เก็บข้อมูล
   Workers & Pages -> KV -> Create namespace  ตั้งชื่อ astd-visits
   กลับมาที่ Worker -> Settings -> Bindings -> Add -> KV namespace
     Variable name : VISITS        (ต้องสะกดแบบนี้เป๊ะ)
     KV namespace  : astd-visits

4) ตั้งรหัสลับสำหรับกวนข้อมูล IP
   Worker -> Settings -> Variables and Secrets -> Add -> Secret
     Name  : SALT
     Value : พิมพ์อะไรยาว ๆ มั่ว ๆ ก็ได้ เก็บไว้อย่าบอกใคร

5) ก๊อป URL ของ Worker (หน้าตาประมาณ https://astd-visitors.xxx.workers.dev)
   เอาไปวางที่บรรทัด VISITOR_API ในไฟล์ assets/js/visitors.js

เสร็จแล้วเปิดเว็บ ตัวเลขผู้เข้าชมจะขึ้นเอง
ถ้ายังไม่ได้ตั้ง ช่องผู้เข้าชมจะซ่อนตัวเอง เว็บทำงานปกติทุกอย่าง


เรื่องความเป็นส่วนตัว
--------------------------------------------
ไม่ได้เก็บ IP ดิบไว้เลย
IP ถูกเอาไปผสมกับ SALT แล้วแปลงเป็นรหัสย่อด้วย SHA-256 เก็บแค่รหัสนั้น
ย้อนกลับไปหา IP เดิมไม่ได้ แต่ยังรู้ว่าเป็นเครื่องเดิมที่เคยเข้ามาแล้ว
ไม่ใช้คุกกี้ ไม่ต้องมีแบนเนอร์ขอความยินยอม


ตัวเลขที่ได้หมายถึงอะไร
--------------------------------------------
total = จำนวน IP ที่ไม่ซ้ำกัน นับตั้งแต่วันแรก
today = จำนวน IP ที่ไม่ซ้ำกันของวันนี้ (รีเซ็ตทุกวันตามเวลา UTC)

ข้อจำกัดที่ควรรู้ (ทุกเว็บที่นับด้วย IP เจอเหมือนกัน):
- คนที่ใช้เน็ตบ้านเดียวกันหรือ WiFi ที่เดียวกัน จะถูกนับเป็นคนเดียว
- เน็ตมือถือเปลี่ยน IP บ่อย คนเดิมอาจถูกนับหลายครั้ง
- คนใช้ VPN จะนับตาม IP ของ VPN
สรุปคือได้ "จำนวน IP" ไม่ใช่ "จำนวนคน" เป๊ะ ๆ แต่ใกล้เคียงพอจะดูแนวโน้มได้

หมายเหตุทางเทคนิค: KV บวกเลขแบบไม่ล็อกคิว ถ้าคนเข้าพร้อมกันเยอะมาก
ในวินาทีเดียวกัน ตัวเลขอาจคลาดไปนิดหน่อย เว็บขนาดนี้ไม่ต้องห่วง
